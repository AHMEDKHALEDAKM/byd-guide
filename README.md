# BYD Showroom Guide

A phone guide to the BYD Egypt line-up for showroom staff: prices, full brochure specs, talking points, car-to-car comparison, every feature across all cars, and rankings. Works offline once opened and can be added to the home screen.

Built from the BYD Egypt model brochures and the 22 October 2026 price list. Not an official BYD app. Confirm any figure marked "check before quoting" with BYD Egypt.

The page is generated: edit the files in the `source` folder next to this repo and run `node build.js`.
